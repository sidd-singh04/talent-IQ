# Real-Time Interview Platform

## Description
A full-stack real-time technical interview platform built using the MERN stack. The platform enables 1-on-1 live coding interviews with video communication, secure code execution, real-time collaboration, and automated feedback based on test cases.

## Features
- VSCode-powered in-browser code editor
- Authentication & authorization using Clerk
- 1-on-1 private video interview rooms
- Live dashboard with real-time stats
- Mic & camera toggle
- Screen sharing & session recording
- Real-time chat messaging
- Secure code execution in isolated environment
- Auto feedback (Success / Fail based on test cases)
- Confetti animation on success
- Failure notifications
- Practice problems page (solo coding mode)
- Room locking (only 2 participants allowed)
- Background jobs with Inngest (async processing)
- REST API built with Node.js & Express
- Data fetching & caching using TanStack Query

## Tech Stack
- Frontend: React.js, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: Clerk
- Code Editor: Monaco Editor (VSCode-powered)
- Real-Time Communication: Stream (Video & Chat SDK)
- Data Fetching: TanStack Query
- Background Jobs: Inngest
- Tools: VS Code, Git & GitHub
